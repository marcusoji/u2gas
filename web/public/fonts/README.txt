U2GAS fonts
===========

The Figma file specifies two faces. Both are freely licensed, so both can be
committed here and served from our own origin.

  jgs7.woff2 / .woff / .ttf     the pixel face — every heading, label, button
  jgs5.woff2 / .woff / .ttf     the LED face — readouts and tickers only
  homemade-apple.woff2 / .woff  the handwriting face — names on profile only

  jgs9.woff2 / .woff / .ttf     the third member of the family; not used by any
                                artboard, kept so the family is complete
  jgs_Font.ttf                  the family master; same, not used on a screen

tokens.css already references these, and scripts/check-assets.mjs fails the
build if any referenced file is missing — so a broken font path cannot ship
unnoticed.

To rebuild after changing the glyph subset, run from the repository root:

    pip install fonttools brotli
    ./tools/fetch-fonts.sh

Commit the results. A font fetched at deploy time is a build that breaks the
day an upstream URL moves.

Sources and licences
--------------------
jgs Font            Adél Faure — github.com/adelfaure/jgs_font
                    jgs7 is the 7px variant, which is what the file specifies.
                    jgs5 and jgs9 are the 10px- and 18px-multiple variants.
                    Keep the upstream LICENSE file next to the font.
                    The upstream repository ships whole as `jgs-main.zip` at the
                    repo root, so the masters can be refreshed from it without
                    network access.

Homemade Apple      Google Fonts, SIL Open Font License 1.1
                    github.com/google/fonts/tree/main/apache/homemadeapple
                    The OFL requires the licence to travel with the font, so
                    keep OFL.txt here too.

Why self-hosted rather than a Google Fonts <link>: a third-party font request
is a render-blocking round trip to a domain we do not control, it leaks every
visitor's IP to that domain, and the pixel face is the brand — it must not
flash. Self-hosting also lets us subset, which takes Homemade Apple from about
100KB to a few KB for the four words it renders.

Fallback, already in place
--------------------------
  u2-pixel-400 / -700   generated by tools/make_pixel_font.py

A 5x7 dot-matrix reconstruction built from the prototype frames before the
real face was identified. It stays in the stack after jgs7 so the app renders
correctly if the licensed file is ever missing. Metric-matched on the same
cell, so swapping causes no reflow.

Type specification from the file
--------------------------------
  Profile menu (HISTORY, PERSONAL DETAILS, SUBSCRIPTIONS)
      jgs7, 400, 56px, letter-spacing -4%, leading trimmed to cap height

  Name on profile ([ Caleb ])
      Homemade Apple, 400, 36px, letter-spacing -4%, leading trimmed to cap height

The -4% tracking is why the type looks tight in the design despite jgs7's own
side bearings. Both are wired as --track and --t-menu / --t-script in
src/styles/tokens.css.

"Leading trim to cap height" has no stable CSS equivalent yet. It is applied
through `text-box: trim-both cap alphabetic` inside an @supports block, so
browsers without it simply use normal leading rather than breaking.
