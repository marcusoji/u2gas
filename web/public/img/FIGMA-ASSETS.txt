How these were obtained
-----------------------
The Figma asset host (www.figma.com) is not reachable from the build sandbox,
so the usual export URLs return 403. These were pulled instead through the
Figma plugin API, which runs inside Figma itself: exportAsync() produces the
bytes and returns them through the tool channel.

Notes worth keeping
-------------------
receipt_union   The torn lower edge is NOT a scallop. It is a nib shape:
                13 teeth, 21.24px pitch, dipping 3.379px below the 159.622
                baseline, each tooth flat-topped with a rounded dip. An
                earlier CSS radial-gradient mask had it as circles, which
                reads wrong at any size above thumbnail.

delete_button   Not a text glyph. The X is drawn as pixel blocks so it sits on
                the same grid as jgs7. Rendering it as "x" in a text node
                gives a visibly different shape.

led legs        4px stroke, 5.58px corner radius. The SVG is 24 wide for a
                22-wide node because the stroke needs the extra room.

How the others were transferred
-------------------------------
The Figma asset host is unreachable from the build sandbox and the plugin
tool result caps at 20KB, so each photo was exported small, base64-encoded,
split into chunks, and reassembled with a per-chunk checksum plus a whole-file
checksum.

That verification was not ceremonial. Two unchunked attempts both produced
corrupt files — one truncated, one the correct length and correctly terminated
but wrong in the middle, which is the kind that passes a casual look. At 2200
characters per chunk, one chunk in three failed. At 1100 characters, none did.
Use 1100 if this ever needs repeating.

For production, export these from Figma directly at full resolution rather
than reusing the reduced-scale copies here.


The receipt QR
--------------
receipt-qr.png is NOT the image from the Figma file. That one is a sample
('copied_data-8 1') whose payload is arbitrary, so copying its exact pixels
would have bought nothing and cost a long, error-prone transfer.

This is a correctly-structured QR matrix at the same module density: real
finder patterns, separators, timing tracks and an alignment block, 25 modules
at 4px. It reads as a QR and carries the right visual weight at 100x100.

It is not scannable, and it does not need to be — the application issues its
own codes through issue_qr() and renders them client-side. Nothing should ever
ship this file; it exists so the receipt layout can be judged.
